## 🧑‍💻 Tentang saya

- 🏛️ Membangun sistem **pajak dan pendapatan daerah** untuk Bapenda Kota Surabaya: monitoring realisasi, reklame, PBJT, PBB, parkir digital, dan bendahara penerimaan.
- 🔄 Menulis **worker service dan tool migrasi** yang menyinkronkan data dari banyak database Oracle dan API vendor.
- 🌐 Full-stack **ASP.NET Core** (MVC, Web API, BFF + JWT) dengan DevExtreme, DevExpress Reporting, dan SSE untuk data real-time.
- 📱 Membuat aplikasi mobile dengan **Flutter**, dari keuangan pribadi sampai tuner alat musik.
- ⚡ Di luar kantor, suka bikin web app ringan dengan **React, Astro, Hono**, dan Google Sheets sebagai database.
